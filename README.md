# Kitchen Rush

Game nấu ăn 3D độc lập lấy cảm hứng từ thể loại quản lý căn bếp. Tài nguyên 3D được tạo bằng mã Three.js; không dùng hình ảnh, nhân vật hoặc bản đồ của Overcooked.

## Chạy

```sh
npm install
npm run dev
```

Mở URL Vite in ra. `npm run build` tạo bản tĩnh trong `dist/`; `npm test` kiểm tra chu trình nấu, giao món, rửa đĩa, cháy nồi và thời gian.

## Chơi

- Người 1: WASD di chuyển, E lấy/đặt, giữ Space thái/rửa/dập lửa, Shift trái lướt.
- Người 2: mũi tên di chuyển, Enter lấy/đặt, giữ / hoặc Numpad 0 thao tác, Shift phải lướt.
- Bật chế độ 2 người bằng nút trên góc phải sân chơi. ESC tạm dừng.
- Lấy nguyên liệu → đặt lên thớt → giữ Space → lấy nguyên liệu đã thái → cho 2 phần đúng công thức vào nồi → chờ 10 giây → lấy đĩa → múc súp → giao món.
- Các món: 2 cà chua, 2 hành, 2 nấm, hoặc 1 cà chua + 1 nấm. Rửa đĩa bẩn ở bồn sau khi giao món.
- Súp sẽ cháy sau 23 giây kể từ khi chín. Giữ phím thao tác ở nồi, tay không, để dập lửa.
- Ca làm 4 phút; 150/350/600đ đạt 1/2/3 sao. Kỷ lục và âm thanh được lưu trong trình duyệt.

Một màn chơi, tối đa 2 người cùng bàn phím; chưa có chơi mạng. Thiết bị cảm ứng có nút điều khiển trên màn hình.
